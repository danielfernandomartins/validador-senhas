# 🔐 Validador de Senhas em Java

Aplicação de console para verificar se uma senha atende a critérios definidos de complexidade.

## Regras implementadas

- Tamanho mínimo
- Pelo menos uma letra maiúscula
- Pelo menos uma letra minúscula
- Pelo menos um número
- Pelo menos um caractere especial
- Sem espaços em branco

## Tecnologia

**Java**

## O que demonstra

- Manipulação de strings
- Condicionais
- Validações
- Regras combinadas
- Mensagens de feedback ao usuário

## Como explicar em entrevista

> "O projeto transforma uma política de senha em regras verificáveis. O desafio foi validar vários critérios independentes e informar ao usuário exatamente quais requisitos não foram atendidos."

## Limite do projeto

Validação de complexidade não substitui práticas completas de autenticação, hashing e segurança.
